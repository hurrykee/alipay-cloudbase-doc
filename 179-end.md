# end

返回文档标记聚合流水线完结，发起实际的聚合操作请求。
```
<?php
public function end(): array
```


## 请求参数

无。

## 返回参数

聚合操作结果记录列表。

## 示例


```PHP
<?php

use Cloud\Cloud;
function aggregateEnd($event, $context): array
{
$logger = $context->getLogger();
$cloud = new Cloud();
$database = $cloud->database();
$command = $database->command;
$aggregateCommand = $command->aggregate;
$aggregateArray = array(
"_id" => "$" . "class",
"avg" => $aggregateCommand->avg("$" . "some-field-name")
);
$result = $database
->collection("collectionName")
->aggregate()
->group($aggregateArray)
->end();
$logger->info("end", "end response:%s", json_encode($result));
return $result;
}
```
