# 日志打印

返回文档

## 日志打印


```
<?php

public function debug(string $action, string $format, ...$values)
public function info(string $action, string $format, ...$values)
public function warn(string $action, string $format, ...$values)
public function error(string $action, string $format, ...$values)
```


## 请求参数


| 字段名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| action | string | 是 | 日志标识。 |
| format | string | 是 | 日志格式。 |
| values | 可变参数 | 否 | 日志渲染数据。 |


## 返回参数

无。

## 示例


```PHP
<?php
function main($event, $context)
{
$logger = $context->getLogger();
$logger->info("index", "got event=%s", json_encode($event));
return $event;
}
```
