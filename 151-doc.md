# doc

返回文档获取集合中指定的文档 client，需通过 id 参数指定文档的 id。
```
<?php
public function doc(string $id): Document
```


## 请求参数


| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | 无 | 文档 id。 |


## 返回参数

Document client.

## 示例


```PHP
<?php

use Cloud\Cloud;
use Cloud\Mongodb\Document;
function doc($event, $context): Document
{
$logger = $context->getLogger();
$cloud = new Cloud();
$database = $cloud->database();
$doc = $database
->collection("collectionName")
->doc("some-doc-id");
$logger->info("doc", "doc response:%s", json_encode($doc));
return $doc;
}
```
