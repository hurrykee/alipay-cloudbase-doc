# 快速开始

## 1. 实现云函数

客户端可以通过 WebSocket 协议连接到某一个云函数，WebSocket 连接上的所有操作都会转换为云函数接收到的事件。我们使用云函数来实现一个简单的 Echo 服务，它将收到的消息再发回给客户端。在云开发控制台创建一个函数，名为 echo-demo ，通过在线 IDE 编辑代码，共两个文件，内容如下：
```
const cloud = require('@alipay/faas-server-sdk');
const ws = new cloud.Cloud().ws();
addWebSocketEventListener('connect', async event =>{
console.log('new connection, connId=' + event.connectionId);
console.log('event:' + JSON.stringify(event));
});
addWebSocketEventListener('message', async event =>{
console.log('new message, connId=' + event.connectionId);
console.log('event:' + JSON.stringify(event));
await ws.send(event.connectionId, 'echo: ' + event.payload);
});
addWebSocketEventListener('disconnect', async event =>{
console.log('disconnect, connId=' + event.connectionId);
console.log('event:' + JSON.stringify(event));
});
addWebSocketEventListener('error', async event =>{
console.log('error, connId=' + event.connectionId);
console.log('event:' + JSON.stringify(event));
});
```

## 2. 从客户端连接

可以使用各类常见的 WebSocket Client 库发起连接，我们这里使用 wscat 来进行连接，并使用 @alipay/faas-web-sdk 来计算签名。

### 2.1 发起连接

安装 wscat ： npm install -g wscat
```JavaScript
const { Cloud } = require("@alipay/faas-web-sdk");  // 1.1.22或更新版本
const c = new Cloud({
resourceAppid: "2021004100000000",
resourceEnv: "env-00jx40000000",
secretId: "xxxxx",
secretKey: "xxxxx",
});
const url = c.ws().signedURL("echo-demo", {  // echo-demo为示例函数名称
queryString: {
k1: "v1",    // 可传入用户自定义的参数
k2: "v2",
},
});
var socket = new WebSocket(url);

socket.onopen = function(event) {
socket.send("hello");
};
socket.onmessage = function(event) {
console.log("接收消息: " + event.data);
};
socket.onerror = function(event) {
console.log("错误: " + event.error);
};
socket.onclose = function(event) {
console.log("连接关闭，关闭状态码: " + event.code);
};
```
注意：SDK 给出的为ws://链接，云开发同时支持ws://和wss://，可根据需要进行选择。

# 在云函数中处理 WebSocket 消息

## 1. 注册事件处理器

WebSocket 事件有四类：●connect 客户端发起连接●message 客户端发送消息●disconnect 连接断开，客户端发起或服务端发起●error 发生错误event 的结构如下：  通过 addWebSocketEventListener() 为四类事件分别注册 handler 方法即可，不必实现 main 方法。

## 2. 发送消息

从云函数中向客户端传输数据时，可调用 SDK 提供的 send 方法，支持发送文本或二进制消息。  也支持传入 connId 的列表，向一组连接批量发送消息。

## 3. 断开连接

断开连接，与 send 类似，可以单个或批量关闭连接。
| 关闭状态(status) | code | 说明 |
| --- | --- | --- |
| NORMAL | 1000 | indicates a normal closure, meaning that the purpose for which the connection was established has been fulfilled. |
| GOING_AWAY | 1001 | indicates that an endpoint is "going away", such as a server going down or a browser having navigated away from a page. |
| PROTOCOL_ERROR | 1002 | indicates that an endpoint is terminating the connection due to a protocol error. |
| BAD_DATA | 1007 | indicates that an endpoint is terminating the connection because it has received data within a message that was not consistent with the type of the message (e.g., non-UTF-8 [RFC3629] data within a text message). |
| TOO_BIG_TO_PROCESS | 1009 | indicates that an endpoint is terminating the connection because it has received a message that is too big for it to process. |
| SERVER_ERROR | 1011 | indicates that a server is terminating the connection because it encountered an unexpected condition that prevented it from fulfilling the request. |
| SERVICE_RESTARTED | 1012 | indicates that the service is restarted. A client may reconnect, and if it chooses to do, should reconnect using a randomized delay of 5 - 30s. |
| SERVICE_OVERLOAD | 1013 | indicates that the service is experiencing overload. A client should only connect to a different IP (when there are multiple for the target) or reconnect to the same IP upon user action. |
| USER_STATUS_1 | 4991 | custom status for user application |
| USER_STATUS_2 | 4992 | custom status for user application |
| USER_STATUS_3 | 4993 | custom status for user application |
注：用户可使用预定义的 USER_STATUS_1/2/3 表示自定义的关闭状态。
