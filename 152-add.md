# add

返回文档新增文档。
```
<?php
public function add(AddDocumentParam $request): AddDocumentResult
```


## 请求参数

### AddDocumentParam


| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| data | AddManyDocumentParam \| AddOneDocumentParam | 是 | 无 | 新增文档数据。 |


### AddManyDocumentParam


| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| data | AddOneDocumentParam[] | 是 | 无 | 新增文档数据。 |
| ordered | bool | 否 | 无 | 指定有序/无序。 |


### AddOneDocumentParam


| 字段名 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 否 | 无 | 新增文档数据。 |
| data | array | 否 | 无 | - |
| openId | string | 否 | 无 | - |


## 返回参数

### AddDocumentResult


| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 新增文档的 id。 |


## 示例


```PHP
<?php

use Cloud\Cloud;
use Cloud\Mongodb\AddDocumentParam;
use Cloud\Mongodb\AddDocumentResult;
use Cloud\Mongodb\AddOneDocumentParam;
function add($event, $context): AddDocumentResult
{
$logger = $context->getLogger();
$cloud = new Cloud();
$database = $cloud->database();
$id = StringUtil::EMPTY;
$data = array(
"keyOneValue" => "valueOne",
"keyTwoValue" => "valueTwo"
);
$param = new AddOneDocumentParam(
$data,
$id);
$entity = new AddDocumentParam($param);
$result = $database
->collection("collectionName")
->add($entity);
$logger->info("add", "add response:%s", json_encode($result));
return $result;
}
```
