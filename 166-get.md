# get

返回文档获取文档数据。
```
<?php
public function get(): array
```


## 请求参数

无。

## 返回参数

文档信息。

## 示例


```PHP
<?php

use Cloud\Cloud;
function get($event, $context): array
{
$logger = $context->getLogger();
$cloud = new Cloud();
$database = $cloud->database();
$result = $database
->collection("collectionName")
->doc("some-doc-id")
->get();
$logger->info("get", "get response:%s", json_encode($result));
return $result;
}
```
